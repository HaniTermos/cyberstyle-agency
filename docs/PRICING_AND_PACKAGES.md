## 2. Itemized Package Specifications

### Package A: Starter Web & Local SEO ($5,000 – $10,000)
- **Target Client**: Local businesses with missing or outdated websites (cafes, dental clinics, salons, regional advisory).
- **Core Deliverables**:
  - 3–5 page responsive web platform on Next.js 15 and Tailwind CSS.
  - Sub-second mobile loading performance (Google Core Web Vitals 95+).
  - Schema.org Organization, LocalBusiness, and Service JSON-LD.
  - Direct inquiry capture flow with email/WhatsApp notifications.
  - 30-day post-launch warranty and free website monitoring.
- **Sprint Schedule**: 2 Sprints (Sprint 1: Architecture & UI Canvas; Sprint 2: Build & Production Launch).

---

### Package B: Growth Web Platform & AI Automation ($15,000 – $30,000)
- **Target Client**: Growing SaaS startups, medical centers, multi-location brands, and e-commerce companies.
- **Core Deliverables**:
  - Full-stack Next.js 15 web application with authenticated client portal.
  - Gemini AI customer assistant, automated inquiry triage, and CRM integration.
  - Stripe recurring subscription billing and automated invoice generation.
  - Interactive 3D WebGL product visualizer or custom booking canvas.
  - PostgreSQL database schema with automated daily cloud backups.
- **Sprint Schedule**: 3–4 Sprints (Architecture -> Core API & AI Engine -> Client Portal -> QA & Cloud Deployment).

---

### Package C: Dedicated Growth & Retention Retainer ($1,500 – $4,500 / month)
- **Target Client**: Active clients requiring continuous optimization, SLA guarantees, and security monitoring.
- **Core Deliverables**:
  - **24/7 Website Monitoring**: Continuous URL change detection and incident response via `changedetection.io`.
  - **OpenSEO Engine**: Weekly Core Web Vitals audits, Schema.org validation, and Google keyword rank tracking.
  - **Dedicated Sprint Hours**: 15 to 40 hours/month of engineering time for new features, bug fixes, and design updates.
  - **Monthly Retainer Report**: Comprehensive executive PDF statement with SLA uptime certificates, completed deliverables audit, and next-month priorities roadmap.
  - **Priority SLA**: 4-hour critical incident response time.

## 3. Proposal & Contract Terms

1. **Milestone-Based Invoicing**: All project builds require a 50% deposit before kickoff, with subsequent milestone payments escrowed upon client sign-off in the portal.
2. **Human Approval Gate**: All proposals, statements of work, and monthly reports must be reviewed and approved by an admin before becoming visible to the client.
3. **Transparent SLA Reporting**: Retainer clients receive an automated monthly PDF report detailing exact hours used, tasks delivered, and uptime statistics.
