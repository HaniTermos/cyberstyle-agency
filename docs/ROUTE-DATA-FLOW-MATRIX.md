## 1. Overview & Architectural Conventions

This matrix documents every user-facing page and administrative module in the CYBERSTYLE monorepo. It details the exact data lifecycle from user interaction down to PostgreSQL transactions, Redis queues, and external providers:

```
[Browser Component] 
       │
       ▼ (apiRequest / fetch)
[Express Router] (Middleware: RateLimiter -> CorrelationID -> RequireAuth -> RequireRole)
       │
       ▼ (Controller / Handler)
[Domain Service Layer] (Zod Validation -> Audit Logger -> Error Tracker)
       │
       ├────────────────────────┬────────────────────────┐
       ▼                        ▼                        ▼
[Prisma Client (PostgreSQL)] [BullMQ (Redis)] [External Provider Adapter (Stripe, Hostinger SMTP, Gemini)]
```
